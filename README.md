一个用于批量导出小米云服务笔记的 Chrome 浏览器扩展工具。支持导出为 Markdown 格式，自动下载笔记中的图片，支持文件夹选择、暂停/继续功能。

## ✨ 功能特性

- ✅ **批量导出**：支持一次性导出多个文件夹的笔记
- ✅ **Markdown 格式**：导出为标准 Markdown 格式，便于 Obsidian 等笔记软件使用
- ✅ **图片自动下载**：自动识别并下载笔记中的图片到本地
- ✅ **图片并发下载**：默认 4 并发 + 去重，同一张图只抓一次，比逐张串行快数倍
- ✅ **断点续传**：已导出的笔记记在本地，中断或重跑时直接跳过，不会重复下载图片
- ✅ **云端清单核对**：用接口读取真实条数与修改时间，条数当进度分母，导出后逐夹核对有没有漏抓
- ✅ **改动检测**：小米笔记里改了内容，下次导出会自动重抓该文件夹，不会被断点续传跳过
- ✅ **自定义输出目录**：可指定下载到「下载目录」下的任意子目录
- ✅ **打包导出**：可把每个文件夹的 md + json + 图片合成一个 zip，只下载一次
- ✅ **文件夹选择**：可选择性导出特定文件夹的笔记
- ✅ **暂停/继续**：支持导出过程中的暂停和继续
- ✅ **智能防爬虫**：可配置延迟和批量处理，避免被反爬虫检测
- ✅ **进度实时显示**：实时显示导出进度和日志
- ✅ **自动年份补充**：为当年的笔记自动补充完整年份信息
- ✅ **原生侧边栏**：使用 Chrome 原生侧边栏，界面更美观

## 📦 安装方法

### 1. 下载项目

克隆或下载此仓库到本地：

```bash
git clone https://github.com/Horizen5/mi-notes-exporter.git
```

或者直接下载 ZIP 并解压。

### 2. 安装到 Chrome 浏览器

1. 打开 Chrome 浏览器，访问 `chrome://extensions/`
2. 开启右上角的「开发者模式」开关
3. 点击「加载已解压的扩展程序」按钮
4. 选择刚才下载的项目文件夹
5. 确认安装成功，你会在扩展列表中看到「小米笔记导出工具」

### 3. 浏览器兼容性

本扩展支持所有基于 Chromium 的浏览器：
- Chrome 90+
- Edge 90+
- Brave
- Opera
- Vivaldi

## 🚀 使用方法

### 1. 登录小米云服务

1. 访问 [小米云服务 - 笔记](https://i.mi.com/note/h5)
2. 登录你的小米账号
3. 确保可以正常看到你的笔记列表

### 2. 打开扩展侧边栏

1. 点击浏览器工具栏中的扩展图标
2. 或点击地址栏右侧的「小米笔记导出工具」图标
3. 侧边栏会自动打开

### 3. 配置导出选项

在侧边栏中可以配置以下选项：

#### 文件夹选择
- 点击「刷新文件夹列表」获取当前所有文件夹
- 勾选你需要导出的文件夹
- 支持「全选/取消全选」

#### 导出设置
- **导出类型**：
  - 完整导出（含图片）：导出笔记内容并下载所有图片
  - 纯文本导出：只导出文字内容，不下载图片
- **图片文件夹名称**：设置保存图片的文件夹名称（默认为 `images`）

#### 反爬虫设置（建议保持默认）
- **最小延迟**：每次操作之间的最小等待时间（毫秒），默认 1000ms
- **最大延迟**：每次操作之间的最大等待时间（毫秒），默认 3000ms
- **批量大小**：每处理多少条笔记后强制休息，默认 30 条
- **批量休息**：强制休息的时间（毫秒），默认 15000ms

### 4. 开始导出

1. 确认所有设置无误后，点击「开始导出」按钮
2. 扩展会自动：
   - 逐个打开选中的文件夹
   - 逐条提取笔记内容
   - 下载笔记中的图片
   - 保存为 Markdown 文件和 JSON 文件
3. 在导出过程中可以：
   - 点击「暂停」暂停导出
   - 点击「继续」继续导出
   - 点击「停止」结束导出（已处理的笔记会保存）

### 5. 查看导出结果

导出的文件会自动保存到浏览器的默认下载目录；如果设置了「输出目录」（例如 `小米笔记/2026`），则会保存到该子目录下。

打包方式默认是 zip，每个文件夹一个压缩包，文件名就是文件夹名：

```
下载目录/
├── 私密笔记.zip              # 默认：md + json + images/ 合成一个包
├── 工作.zip
└── ...
```

包内结构：

```
私密笔记.zip
├── 私密笔记.md
├── mi_note_私密笔记.json
└── images/
    ├── 私密笔记_260101_ab12cd34_1.jpg
    └── ...
```

### 笔记标题怎么来的

每条笔记的标题取自小米笔记列表里那一行文字，但你**没写标题**时，那行其实是正文开头的预览。所以导出时按「正文是否以这行文字开头」区分：

- 真标题 → `## 关于爱情`
- 没写标题 → 按「标题样式」设置渲染，默认是一行浅灰的「无标题」占位（`## <span style="color:#9aa3af">无标题</span>`，Obsidian / Typora 里显示为灰色小字）

标题样式的另外三档是「留一个空标题」（`##`）、「普通文字「无标题」」、「不输出标题行」。

切到「逐个文件」后是散文件，可以直接放进 Obsidian：

```
下载目录/
├── 文件夹名1.md              # Markdown 格式的笔记文件
├── 文件夹名2.md
├── mi_note_文件夹名1.json    # 原始 JSON 数据
├── mi_note_文件夹名2.json
└── images/                   # 图片文件夹
    ├── 文件夹_YYMMDD_NoteID_1.jpg
    ├── 文件夹_YYMMDD_NoteID_2.jpg
    └── ...
```

## 📄 导出文件说明

### Markdown 文件结构

每个文件夹生成一个独立的 Markdown 文件，格式如下：

```markdown
# 小米笔记导出 - 文件夹名

导出时间: 2026-05-08 14:30:00
笔记数量: 15

> 请将下载的图片放入 images 文件夹

---

## 笔记标题1

> 创建时间: 2026年3月15日

笔记内容...

![图片描述](./images/xxx.jpg)

---

## 笔记标题2

> 创建时间: 2026年3月16日

笔记内容...

---
```

### 图片命名规则

图片文件命名格式：`文件夹名_YYMMDD_NoteID哈希8位_序号.jpg`

例如：`工作_260315_ABCD_1.jpg`

## ❓ 常见问题

### Q: 下载出来的文件叫「下载.zip」而不是文件夹名？

**A:** 不是导出逻辑的问题，是 Chrome 的一个老规则：`chrome.downloads.download()` 传的 `filename`，只要浏览器里存在任何一个注册了 `downloads.onDeterminingFilename` 监听的扩展（IDM、Chrono、各类下载管理器都注册），就会被整体忽略，文件改由 URL 反推命名，data: URL 反推出来就是「下载.zip」。

v1.11.4 之后本扩展自己也注册了这个监听，会重新把「私密笔记.zip」这样的名字建议回去。如果还被改写，侧边栏日志会写明实际名字和被改写的原因，此时临时禁用那个下载管理器类扩展再导出即可。

### Q: 导出过程中页面卡住不动怎么办？

**A:** 请尝试以下方法：
1. 确保小米云服务页面保持在前台
2. 不要最小化浏览器窗口
3. 适当增加延迟时间设置
4. 如果卡住超过 30 秒，可以尝试暂停后继续

### Q: 有些图片下载失败怎么办？

**A:** 图片下载失败的常见原因：
1. 网络不稳定 - 检查网络连接
2. 图片已被删除 - 笔记中的图片可能已失效
3. 小米云服务限制 - 尝试增加延迟时间
4. 登录状态失效 - 重新登录小米云服务

### Q: 如何避免被反爬虫检测？

**A:** 建议配置：
- 增加最小/最大延迟时间
- 减小批量大小
- 增加批量休息时间
- 避免在短时间内多次导出

### Q: 导出中断后可以继续吗？

**A:** 可以。v1.10.0 起支持断点续传：每条笔记导出成功后会把结果记在本地（`chrome.storage.local` 的 `miNotesCache`），下次运行时命中记录的笔记直接复用，不再点开、不再下载图片。

- 想强制全部重导：设置页关闭「断点续传」，或点「清除断点记录」
- 改了内容的笔记不会被漏掉：v1.11.0 起会比对云端 `modifyDate` 与上次导出时间，发现更新的文件夹自动强制重抓，日志里会写明
- 打包（zip）模式下不启用断点续传，因为图片只存在于当次内存中，跳过后压缩包会缺图

### Q: 「云端清单」是什么？关掉会怎样？

**A:** 它是一次只读接口请求（`i.mi.com/note/full/page/`），拿回文件夹列表、每个文件夹的真实条数、每条笔记的修改时间与正文摘要。**正文仍然从页面 DOM 取**，所以 Markdown 转换结果和以前完全一样。

关掉它会失去三样东西：进度条的分母退回解析页面那句「共 N 条笔记」（改版就没了）、改了内容不会被检测到、导出后没有漏单核对。

接口不通（未登录、超时、小米改接口结构）时会自动退回页面解析，不影响导出。设置页的「测试接口」按钮可以单独验证它通不通。

### Q: 为什么有些笔记没有标题？

**A:** 小米笔记中有些笔记可能没有设置标题，导出时会显示为「无标题」。

### Q: 可以在其他浏览器使用吗？

**A:** 可以！所有基于 Chromium 的浏览器（Edge、Brave、Opera 等）都支持，安装方法相同。

## 🔧 技术细节

### 扩展架构

- **Manifest V3**：使用最新的 Chrome 扩展规范
- **Content Script**：运行在小米云页面中，负责抓取笔记
- **Background Service Worker**：处理文件下载等后台任务
- **Side Panel**：使用 Chrome 原生侧边栏提供用户界面

### 数据安全

- 所有数据处理都在本地浏览器中进行
- 不上传任何数据到第三方服务器
- 只需要访问小米云服务（i.mi.com）的权限
- 使用 Chrome Storage API 保存配置和进度

### 文件命名过滤

自动过滤文件名中的特殊字符：
- `[ ] 【 】 ( ) （ ）` 等括号和空格会被移除
- `\ / : * ? " < > |` 等非法字符会被替换为 `_`
