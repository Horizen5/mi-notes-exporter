# 小米笔记导出工具 · 使用说明

版本 1.11.6 ｜ 更新 2026-11-01

> 这是**方式一（浏览器扩展）**的说明，不需要 root。
> 手机上已经有 root、想连私密笔记一起导出的话看 [使用说明-root.md](使用说明-root.md)，加密原理见 [原理-私密笔记加密.md](原理-私密笔记加密.md)。

## 一、安装

### 首选：加载已解压扩展（一定能成）

Chrome 从很早的版本开始就禁止从商店外直接安装 .crx，拖进去会提示"只能从 Chrome 应用商店添加"。所以走这条路：

1. 地址栏输入 `chrome://extensions/` 回车
2. 右上角打开「开发者模式」开关
3. 左上角点「加载已解压的扩展程序」
4. 选择文件夹：`D:\Users\Administrator\Documents\Ai\小米便签获取工具`
5. 列表里出现「小米笔记导出工具 1.11.6」即成功

已经装过旧版的，点扩展卡片上的刷新图标即可，不用重新添加。

注意：这个文件夹**不能删也不能移动**。Chrome 是链接到它的，挪走扩展就失效。想换位置，先删扩展再重新加载。

### 备选：装 CRX

`D:\Users\Administrator\Documents\Ai\小米便签获取工具.crx`

如果哪天换成了允许本地 CRX 的浏览器（Chrome for Testing、部分 Chromium 发行版、或企业策略环境），打开 `chrome://extensions/` 开启开发者模式，把 .crx 直接拖进页面即可。

同目录的 `小米便签获取工具.pem` 是签名私钥，**别删**。以后重新打包要用它来保住同一个扩展 ID，不然装上去会变成另一个扩展、配置全部丢失。

## 二、用起来

1. **登录**：新标签页打开 `https://i.mi.com/note/h5`，扫码或账号密码登录，确认左边能看到你的笔记列表
2. **开侧边栏**：在小米页面停留时，点工具栏的扩展图标（橙色便签那个）。侧边栏从右边滑出。如果图标是灰的点不动，说明当前标签不是 i.mi.com
3. **刷文件夹**：侧边栏里点「刷新文件夹列表」，勾选要导的文件夹。第一次用建议只勾一个小文件夹试水
   - 列表顺序与左侧小米导航栏一致，按位置找即可
   - 「私密笔记」**默认不勾选**（没解锁就导出只会白跑），要用时手动勾上或点「全选」，并先在页面上输密码解锁
4. **设参数**：切到「设置」页看一眼这几项，其余保持默认即可：
   - **输出目录**：填 `小米笔记/2026` 就会存到 `下载/小米笔记/2026/`；留空则直接在下载目录
   - **图片并发**：默认 4。网络差可以降到 2，别超过 6
   - **请求间隔**：默认 120ms，控制的是发起频率不是干等，一般不用改
   - **打包方式**：想直接拖进 Obsidian 就用「逐个文件」；想一个压缩包搬走就用「zip」。压缩包按文件夹命名，导出「私密笔记」得到的就是 `私密笔记.zip`，包内是 `私密笔记.md` + `mi_note_私密笔记.json` + `images/`
   - **断点续传**：默认开。中断后重跑会自动跳过已导出的笔记，只补新的
   - **云端清单**：默认开。发一次只读请求拿文件夹条数和修改时间，用来算进度分母、发现改过的笔记、导出后核对漏抓。关掉不影响导出，只是失去这三样
   - 反爬那组保持 1000–3000ms、30 条休 15 秒，别把延迟压到 500ms 以下
5. **开始导出**：点「开始导出」，之后**不要切走标签页、不要最小化窗口**。content script 要读页面 DOM，后台标签会被降频，表现就是卡住不动

过程中可以暂停、继续、停止。停止后已处理的笔记是保存了的。

装好之后想确认新功能生效了，点一下设置页的「测试接口」，日志里会显示「接口可用：N 个文件夹 / M 条笔记」。如果显示不可用，导出会自动退回原来的页面解析方式，照样能跑。

## 三、导出结果在哪

都在 Chrome 的默认下载目录，一般是 `C:\Users\Administrator\Downloads\`：

```
Downloads/
├── 工作.md                    # 每个文件夹一个 Markdown
├── mi_note_工作.json          # 同名 JSON 原始数据
└── images/
    └── 工作_261101_A1B2C3D4_1.jpg
```

Markdown 里图片用的是 `./images/xxx.jpg` 相对路径。要放进 Obsidian，**把 .md 和 images 目录一起复制**到库里，图片才不会断链。

## 四、卡住了怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 更新扩展后侧边栏显示「同步失败」、文件夹一直「正在加载」 | 页面里的旧脚本随扩展更新失效了 | 1.11.3 起会自动重载页面并重新同步，不用手动 F5。如果提示「请重新打开侧边栏」，把侧边栏关掉再点图标 |
| 文件夹列表刷不出来，或全是「未命名文件夹」 | 小米改前端了，CSS 类名变了 | 1.11.0 起文件夹列表优先走接口，这条基本不会再出现。如果还出现，先点「测试接口」看是不是接口也不通 |
| 日志一直停在「正在抓取图片」 | 图片请求超时 | 1.9.5 已修，30 秒自动跳过继续下一条。若还卡，说明卡在别处，把日志截图发我 |
| 导到一半浏览器崩了/关了标签 | 断点记录能救 | 1.10.0 起重跑会自动跳过已导出的。想从头来就点「清除断点记录」 |
| 导出的图全是 .jpg 但实际是 PNG | 1.9.5 之前的 bug | 已修，确认版本不低于 1.9.5 |
| 提示下载失败但没有文件名 | 登录态失效 | 回 i.mi.com 重新登录，再点开始导出 |
| 日志出现「核对不完整：N 条疑似漏抓」 | 页面没滚到那几条，或摘要比对误报 | 只提示不阻断。把日志里那几条的摘要拿去小米笔记里搜一下，真缺就重跑该文件夹 |
| 日志出现「云端有 N 条修改，本次强制重新抓取」 | 正常行为 | 说明你在小米笔记里改过内容，工具主动重抓，不是故障 |
| 文件夹列表里没有「私密笔记」 | 1.11.0 的回归：排除名单误伤 + 接口不返回这个夹 | 1.11.1 已修，列表末尾会多出「私密笔记」，条数显示 `-` |
| 导出「私密笔记」时提示「5 秒内没出现任何笔记列表」 | 私密笔记还锁着，密码没输 | 在小米页面点开私密笔记，输入密码解锁、看到笔记列表后再点开始导出 |

## 五、改了代码怎么生效

改完 content.js / sidepanel.js 后，回到 `chrome://extensions/`，点扩展卡片上的**刷新图标**，再刷新 i.mi.com 页面。两步都要做，少一步跑的还是旧代码。

## 附：版本改动

### 1.11.5 相对 1.11.0

| 改动 | 说明 |
|---|---|
| 压缩包命名 | 下载名被浏览器改写成「下载.zip」时，后台自己参与一次命名建议，把「私密笔记.zip」这种名字抢回来；仍被改写时侧边栏会点明是下载管理器类扩展在抢 |
| 打包方式默认 | 默认从「逐个文件」改成「每个文件夹打成一个 zip」，老配置自动迁移一次 |
| 标题行 | 区分「真标题」与「列表里的正文预览」；没写标题的笔记按「标题样式」渲染，默认浅灰占位「无标题」 |
| 标题样式 | 新增下拉框：浅灰占位 / 留空标题 / 普通「无标题」 / 不输出标题行 |
| 扩展更新 | 更新后侧边栏不再要求手动 F5，自动重载页面并重新同步（1.11.3 起） |
| 文件夹顺序 | 与左侧侧边栏一致（1.11.2 起） |
| 图标 | 恢复蓝底小米云图标（1.11.6 修：1.11.5 曾误用 GitHub 远端的橙底图标） |

### 1.11.0 相对 1.10.0

| 改动 | 说明 |
|---|---|
| 云端清单 | 用接口（`i.mi.com/note/full/page/`）读文件夹、真实条数、每条修改时间。正文仍从页面取，转换结果不变 |
| 进度分母 | 改用接口条数（与页面显示取较大值），那句「共 N 条笔记」改版消失也不影响 |
| 改动检测 | 你在小米笔记里改过内容，该文件夹本次自动重抓，不再被断点续传当成"已导出"跳过 |
| 漏单核对 | 每个文件夹导完报「云端 X / 本地 Y」，把疑似漏抓的列出来 |
| 文件夹匹配 | 接口名与侧边栏名有空格或括号差异时，加两级兜底，不再报"未选择任何文件夹" |
| 失败降级 | 接口不通（未登录/超时/改版）自动退回页面解析，不阻断导出 |
| 设置项 | 新增「云端清单」开关和「测试接口」按钮 |

### 1.10.0 相对 1.9.5

| 改动 | 说明 |
|---|---|
| 图片并发下载 | 从"抓一张睡 1 秒"改成 4 并发 + 请求节流；同一篇里重复的图只抓一次 |
| 断点续传 | 每条笔记导出后记入本地缓存，重跑时整条跳过；设置页可清除 |
| 自定义输出目录 | 下载到「下载目录」下的任意子目录 |
| 打包导出 | 可选把 md + json + 图片合成单个 zip |
| 权限 | 新增 `unlimitedStorage`，避免缓存撑爆默认配额 |

### 1.9.5 相对 1.9.4

| 问题 | 改法 |
|---|---|
| 图片下载失败会让导出永久卡死 | 成功/失败/超时三条路径都会返回，失败只记日志继续 |
| 所有 PNG 都存成 .jpg | 扩展名按 MIME 整体替换，不再只匹配 `.png$` |
| 图片名可能撞车静默覆盖 | 哈希后缀 4 位改 8 位 |
| 文件夹名可能全变「未命名文件夹」 | 选择器加三级兜底 |
| `maxImageSize` 定义了从未生效 | 下载前比对体积，超限跳过 |
